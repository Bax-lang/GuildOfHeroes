## Собственный проект

Тема проекта: Каталог игр

Главный класс: `Game`

Почему этот объект нужен программе:
Класс `Game` позволяет объединить все характеристики одной компьютерной игры в единую структуру, чтобы удобно создавать каталог игр и управлять каждой игрой как отдельным независимым объектом.

Какие данные хранит объект:

- `Title` (`string`) — название игры
- `Genre` (`string`) — жанр игры
- `ReleaseYear` (`int`) — год выхода
- `Rating` (`double`) — оценка игры
- `IsInstalled` (`bool`) — установлена ли игра на компьютер

Какие значения задаются через конструктор:
Через параметры конструктора задаются `title` (название), `genre` (жанр) и `releaseYear` (год выхода).

Какие значения можно задавать автоматически:
Автоматически при создании объекта задаются начальный рейтинг `Rating = 0.0` и статус установки `IsInstalled = false`.

### Дополнительное задание
Какое значение я решил задавать автоматически и почему?
Я решил автоматически задавать поле `IsInstalled = false` (и начальный `Rating = 0.0`), потому что при добавлении новой игры в каталог она по умолчанию ещё не установлена на компьютер пользователя и не имеет оценки, поэтому передавать эти значения каждый раз вручную в конструктор не нужно.
